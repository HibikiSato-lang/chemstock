# ChemStock 新UI案（下部タブバー導入）

既存UI（`スクリーンショット 2026-07-01 16.18.09 copy.png`）のデザインを踏襲し、
**下部タブバー（5タブ）を追加する**形で新機能のUIを設計する。
既存画面の主要な遷移は維持する。研究室選択と在庫表示範囲は確定済みの認可設計に合わせて更新する。遷移の全体像は [画面遷移図](画面遷移図.md) を参照。

見た目の確認は **[ui-mockup/index.html](ui-mockup/index.html)**（HTMLモックアップ・ブラウザで開く）を推奨。

---

## 1. デザイントークン（既存UIから抽出）

| 要素 | 値・スタイル |
|---|---|
| 画面背景 | ミントグリーン（`#D5EBE1` 前後） |
| 主ボタン | 濃緑（ダークティール `#2E6B58`）＋白文字、角丸小 |
| カード・テーブル | 白背景、細いグレー罫線 |
| 画面ヘッダー | 上部に画面タイトル（太字）、右上にホームアイコン |
| 戻る導線 | 「← ○○に戻る」の青い下線リンク（画面左上） |
| フォーム | 縦積み。所属研究室は固定表示（全体管理者のみ研究室を選択）。溶媒はラジオ風リスト、選択肢はプルダウン |
| 確認・完了 | 中央寄せの白パネル＋濃緑ボタン |

**タブバー（新規）**：白背景・上辺に細罫線・高さ約56px。アイコン＋小ラベルの5項目。
アクティブタブは濃緑（`#2E6B58`）、非アクティブはグレー。ログイン画面以外の全画面で固定表示。

```
├───────┬───────┬───────┬───────┬───────┤
│  🏠   │  ✏️   │  🔍   │  📈   │  ⚙️   │
│ ホーム │登録使用│  在庫  │ グラフ │  管理  │
└───────┴───────┴───────┴───────┴───────┘
```

右上ホームアイコン・「← 戻る」リンクは既存のまま残す（タブバーと併存して問題ない）。

## 3. 登録・使用タブ（既存の残量調整＋履歴入口）

研究室・溶媒庫管理アカウントは、所属研究室（`accounts.room_id`）を固定表示し、部屋選択を出さない。全体管理者だけ研究室を選択してから入出庫する。選択したIDはサーバー側でもロールと照合する。溶媒選択→残量調整→追加/使用の流れは維持する。
ヘッダー右に**「履歴」リンクを追加**（§4の入出庫履歴一覧へ）。

| アカウント | 研究室の表示と操作 |
|---|---|
| 研究室・溶媒庫管理 | 所属研究室名を固定表示。研究室の変更操作は出さない |
| 全体管理者 | 入出庫・履歴編集では対象研究室を選択する。直接URLで在庫詳細を参照する場合も、サーバーで対象を検証し研究室名を表示する。確認・完了画面にも研究室名を表示する |

画面を戻っても同じ操作フロー内では対象研究室を保つ。全体管理者が研究室を変更したときは、選択中の溶媒・在庫・履歴をクリアして別研究室への誤操作を防ぐ。

```
┌─────────────────────────┐
│ 残量調整      [🕘履歴] 🏠 │ ← 「履歴」リンク ★新規
│ 研究室：山田研            │ ← 所属アカウントから自動表示
│ ○溶媒選択               │
│ ┌─────────────────────┐ │
│ │ ◯ メタノール ◯ …     │ │
│ └─────────────────────┘ │
│ 残量調整 [−1L] 3.5L [+1L]│
│ ☑追加する ☐使用する      │
│          [確認画面]      │
├─🏠─┬──✏️──┬─🔍─┬─📈─┬─⚙️─┤ ← 登録・使用がアクティブ
└─────────────────────────┘
```

確認・完了画面では、操作対象の研究室名を表示する。全体管理者も選択した研究室を確認してから実行する。

## 4. 入出庫履歴一覧・取消・編集 ★新規

```
┌─────────────────────────┐
│ 入出庫履歴            🏠 │
│ ← 残量調整に戻る          │
│ 研究室：山田研 [溶媒▼]   │ ← 所属研究室を固定表示
│ ┌─────────────────────┐ │
│ │10/9 メタノール +3.0L  │ │ ← 白テーブル（既存の履歴表と同形式）
│ │     学生A [編集][取消] │ │
│ │10/7 アセトン −1.0L    │ │
│ │     学生B [編集][取消] │ │
│ └─────────────────────┘ │
│      [さらに表示]        │ ← ページング
├─🏠─┬──✏️──┬─🔍─┬─📈─┬─⚙️─┤
└─────────────────────────┘
```

- **取消**：確認ダイアログ（白パネル）「この記録を取り消しますか？」＋実操作者名・理由の入力 → 在庫再計算＋監査記録。
- **編集**：同レイアウトのフォームで数量・日付を修正 → 確認ダイアログ → 再計算＋監査記録。
- 履歴と取消・編集の対象は研究室・溶媒庫管理アカウントでは所属研究室のみ。全体管理者は選択した研究室の履歴を表示する。

## 5. 在庫タブ（所属研究室を固定）

既存の在庫検索 → 在庫一覧 → 詳細情報を維持する。研究室・溶媒庫管理アカウントでは検索対象を所属研究室に固定し、部屋の絞り込みを出さない。全体管理者は研究室を選択して表示する。
**詳細情報にだけ「在庫下限設定」ボタンを追加**（§6）。

## 6. 在庫下限設定 ★新規（詳細情報から）

```
┌─────────────────────────┐
│ 詳細情報              🏠 │
│ ← 在庫一覧に戻る          │
│ ┌── 山田研 メタノール ─┐ │
│ │ CAS番号 67-56-1  …    │ │ ← 既存のまま
│ ├──────────────────────┤ │
│ │ 下限値: 5.0 L [⚙変更]  │ │ ← ★新規 行を1行追加
│ └──────────────────────┘ │
│ （履歴テーブル 既存）      │
├─🏠─┬─✏️─┬──🔍──┬─📈─┬─⚙️─┤
└─────────────────────────┘
```

「⚙変更」タップで**ダイアログ**（画面遷移させない）：下限値の数値入力＋[保存]／[キャンセル]。

## 実装メモ

- タブバーは認証後レイアウト（例：`app/(authenticated)/layout.tsx` 相当）に1箇所実装し、`usePathname` でアクティブ判定。各既存ページのコードには手を入れない。
- コンテンツ下端がタブバーに隠れないよう、メイン領域に `padding-bottom: 72px` 程度を確保。
- 「管理」タブ内の管理者項目はロール判定で出し分け（タブ自体は全ロール5つで固定）。
