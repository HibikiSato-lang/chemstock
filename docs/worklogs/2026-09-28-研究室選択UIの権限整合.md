# 研究室選択UIの権限整合

- 日付：2026-09-28
- 状態：画面設計・HTMLモックアップ・Figma生成コード・実装タスクを更新済み。実アプリの画面・認可は未実装。
- リポジトリ・版：ChemStock、`dxproject-2026`、ベース `63d6ca9`、未コミット。

## 目的と判断

確定済みの認可設計では、研究室アカウントと溶媒庫管理アカウントが操作できる研究室別在庫・履歴は、`accounts.room_id`の所属研究室だけである。旧UI案と一部モックアップには「溶媒庫」「学生実験室」などを自由に選ぶ部屋選択が残り、誤操作と実装時の権限誤解を招く状態だった。

研究室・溶媒庫管理アカウントには所属研究室名を固定表示し、研究室の切替操作を出さない。全体管理者は対象研究室を明示的に選択してから在庫・入出庫・履歴を操作する。確認・完了画面には対象研究室名を表示する。サーバー側でもロールと所属を照合し、URLや送信パラメータだけで他室を扱えないようにする。旧`/inventory/[roomId]`は本線から接続せず、残す場合は同じ認可を通す。
