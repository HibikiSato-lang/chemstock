# SBA法による出庫量予測

更新日：2026-10-12。`feature/stock-risk`の試行実装。実Supabaseへの適用・実データでの精度評価は未実施。

利用者の希望に合わせ、表示対象を「今後の予測出庫量（L）と下限までの余裕」とした。従来の重複7日区間の実績割合から、論文で定義されたSyntetos–Boylan Approximation（SBA）へ変更する。以前の[設計案](下限到達リスク_設計案.md)は旧方式の記録として残す。

## 採用理由と文献の確認範囲

出庫のない日が多い履歴では、出庫がある日の数量と、出庫と出庫の間隔を分ける方式が課題に合うと判断した。SBAはCrostonの数量／間隔の平滑化に補正係数を加える方式である。

- Syntetos, A. A., & Boylan, J. E. (2005). *The accuracy of intermittent demand estimates*. International Journal of Forecasting, 21(2), 303–314. [DOI: 10.1016/j.ijforecast.2004.10.001](https://doi.org/10.1016/j.ijforecast.2004.10.001)。確認日2026-10-12、**原著の要旨のみ**。[著者所属機関の記録](https://salford-repository.worktribe.com/output/1474808/the-accuracy-of-intermittent-demand-estimates)で、間欠需要の推定法を実系列で比較した研究であることを確認した。本文の式・実験表は未確認。
- Teunter, R. H., Syntetos, A. A., & Babai, M. Z. (2011). *Intermittent demand: Linking forecasting to inventory obsolescence*. European Journal of Operational Research, 214(3), 606–615. [DOI: 10.1016/j.ejor.2011.05.018](https://doi.org/10.1016/j.ejor.2011.05.018)、[著者所属機関の掲載版PDF](https://pure.rug.nl/ws/portalfiles/portal/145394864/Intermittent_demand_Linking_forecasting_to_inventory_obsolescence.pdf)。確認日2026-10-12、**§2、§3.1、§3.3、§3.4、§4、§6を確認**。SBAの補正係数と更新の性質は、SBA原著者を含むこの論文の§2（掲載p.607）に基づく。§3.1はTSBの更新式、§3.3は係数選択の議論、§3.4は出庫停止時の性質を確認した。
- Shenstone, L., & Hyndman, R. J. (2005). *Stochastic models underlying Croston’s method for intermittent demand forecasting*. Journal of Forecasting, 24(6), 389–402. [著者公開PDF](https://robjhyndman.com/papers/croston.pdf)。確認日2026-10-12、**Croston’s Method節（掲載p.390、式1〜3）を確認**。数量と間隔の指数平滑化を確認する根拠に用いた。全文精読ではない。

SBAの原著本文を直接読めたとは扱わない。補正式は2011年論文の説明を確認して採用した。文献は溶媒庫での精度、7日という期間、365日という参照範囲、2出庫日という表示条件を保証しない。

| 候補 | 今回の判断 |
|---|---|
| 単純な期間平均 | 比較対象として残す。窓の切れ目や出庫頻度の変化に影響されるため、SBAを試行する |
| Croston | 数量・間隔の分離を使う。補正を加えるSBAを採用 |
| SBA | 間欠的な出庫が今後も続くという仮定での平均的な出庫量を出す。今回の試行方式 |
| TSB | 出庫が止まったときも更新する候補。日次の発生確率の係数選択が必要で、少ない出庫から使用終了を判断する根拠はまだない。実データでの比較候補とする |
| bootstrapによる累積需要分布 | 将来の分布・確率を出す場合の候補。今回の平均出庫量の表示とは用途が異なる |

これは課題との適合性に基づく採用判断であり、ChemStockでSBAが最良だったという評価結果ではない。

## 数式

`y_t`を日本時間の日付`t`に記録された有効な出庫量の合計Lとする。入庫は含めず、同日の複数出庫は合計する。出庫がなければ0である。

正の出庫があった日の番号を`t_j`、その日別合計を`x_j = y_(t_j)`、直前の出庫日との間隔を`q_j = t_j - t_(j-1)`とする。

```text
z_j = (1 - α) z_(j-1) + α x_j     平滑化した正の出庫量（L）
p_j = (1 - α) p_(j-1) + α q_j     平滑化した出庫間隔（日）
f   = (1 - α/2) z_j / p_j         SBAによる日平均の予測出庫量（L/日）
F_H = H × f                       H日間の予測出庫量（L）
M_H = A - B - F_H                 予測出庫後の下限までの余裕（L）
```

`A`は読取時の現在量、`B`は研究室が設定した下限値。出庫のない日は`z`・`p`を更新しないが、次の正の出庫までの日数には含める。補正前の`z/p`がCroston方式で、`1-α/2`がSBAの補正である。補正により、すべての需要過程で偏りが消えるという意味ではない。

`M_H > 0`は予測上の余裕、`M_H = 0`は下限と同量、`M_H < 0`は下限に対する不足を示す。不足量は物理的な負の在庫とは区別する。現在既に`A <= B`なら、従来の「下限以下」を優先する。

### 数値例（合成履歴）

現在6 L、下限4 L、出庫が30日間隔で毎回2.5 L、`α=0.1`なら、十分に同じ間隔が続いた例で`z=2.5`、`p=30`となる。

```text
f   = 0.95 × 2.5 / 30 = 0.079166… L/日
F_7 = 7 × f          = 0.554166… L
M_7 = 6 - 4 - F_7    = 1.445833… L
```

画面は「7日間の予測出庫量：約0.55 L」「予測出庫後、下限までの余裕：約1.45 L」とする。**次の出庫で0.55 L取り出すという予測ではない**。次に2.5 Lをまとめて取り出せば下限を割る可能性がある。出庫予定日や1回の予定量が分かる場合、その予定の確認が別途必要である。

## ChemStockで選んだ試行条件

| 項目 | 実装と理由 |
|---|---|
| 期間 | 7日。既存の見通し期間を引き継ぐ。納期の推定ではない |
| 平滑化係数 | 数量・間隔とも`α=0.1`。2011年論文§3.3で紹介されるCroston系の固定係数範囲内での試行値。最適化結果ではない |
| 初期値 | 最初の正の出庫量を`z`とし、最初に観測できた2出庫日の間隔を`p`とする。2回目から数量を平滑化し、3回目から間隔も平滑化する。記録開始〜初出庫は完全な出庫間隔と分からないため使わない。これは本実装の初期化方針 |
| 参照範囲 | 確認済み・利用再開後の最大365完全日。月1回の出庫も複数間隔を取り込みやすくする試行値。季節性をモデル化する意味ではない |
| 当日の扱い | 日本時間の前日終了までの完全な日次記録を使う。開始日も途中時刻なら翌日から。途中の日を少ない使用量として学習しない。当日の入出庫は現在量`A`に反映される |
| 数値表示 | 完全日が2日以上、異なる2日以上に出庫があること。間隔を1つ観測するための**計算可能性の条件**で、予測の信頼性を示す基準ではない。画面に試行・精度未検証を明示 |
| 在庫ゼロの継続 | 観測出庫が真の需要を表さないため、その後の補充日の次の完全日から計算を再開する。欠損日を取り除いて時間を圧縮しない |
| 記録の品質 | 管理者確認、訂正・取消後の再確認、残高照合、利用停止・再開の既存チェックを引き継ぐ |
| 注意行 | `F_7 >= A-B`なら表示し、不足が大きい順に並べる。旧方式の割合20%条件は使用しない |
| 数量精度 | 実績量は0.01 L単位。予測量は小数6桁に丸めて返し、同じ返却精度で注意を判定する。画面は約0.01 L単位、正の微量は「0.01 L未満」とする。日率の丸め値から7日量を再計算しない |

## 限界と評価方針

SBAは出庫がない間に予測を減らさない。研究終了・計画変更で出庫が止まる場合や、急なまとめ出庫、季節性には弱い。需要の分布・下限到達確率・到達日を出す方式として扱わない。論文の部品在庫の結果を溶媒の精度として引用しない。

精度検証は今後行う。過去時点に利用可能だった記録・監査状態だけを復元するか、今後の試行で入力・係数・予測を保存し、未来7日間の出庫実績と比較する。現在の訂正後履歴をそのまま過去時点へ持ち込まない。

比較対象は単純な30日平均、Croston、SBA、TSB。係数・参照期間の選択には先の期間を使い、最終評価期間を分ける。7日累積量のMAE・平均符号付き誤差、予測を出せた在庫数、出庫頻度別の誤差を確認する。出庫0が多いためMAPE単独で判断しない。下限判断は、補充や下限変更等の介入を区別して見逃し・表示負担も評価する。

今回の合成ケースの検証は数式・境界・DB一致の検証であり、予測精度の実証ではない。

## 2026-10-12追記：補正係数の理論と規則的な出庫

利用者への詳しい説明に向け、Syntetos本人の博士論文 *Forecasting of intermittent demand*（2001）の[大学リポジトリ掲載PDF](https://bnu.repository.guildhe.ac.uk/9960/1/A%20%20Syntetos%20%28PhD%20thesis%202001%29.pdf)で§4.5.2〜4.7、掲載p.58〜63、式4.29〜4.37を確認した。全文精読ではなく、2005年の雑誌論文本文を確認したという意味でもない。

量の平均を`μ`、間隔の平均を`q̄`、平滑化した間隔を`P`とする。定常・独立な幾何分布の間隔と数量／間隔の独立性等を仮定し、比の2次Taylor近似から次を得る。

```text
E[Z/P] ≈ (μ/q̄) × {1 + α/(2−α) × (1−1/q̄)}
補正係数 c ≈ 1 / {1 + α/(2−α) × (1−1/q̄)}
            = (1−α/2) / (1−α/(2q̄))
q̄が大きいと c ≈ 1−α/2
```

上式は同博士論文の近似に沿う説明で、すべての出庫過程に対する厳密な不偏性を示さない。SBAの係数は、長い出庫間隔を想定した簡略化として理解できる。

本実装で毎回30日間隔・2.5 Lという完全に規則的な合成例では、補正前の日率`2.5/30`が長期平均に一致する。一律の係数0.95を掛けるSBAはその平均より5%小さくなる。これは現在の式からの算術的帰結であり、論文の実験結果ではない。日付が決まった出庫に対し、SBAが常に優れるとは説明しない。

また`α=0.1`では旧推定値の重みは更新ごとに0.9倍になり、約6.58回の正の出庫日で半分になる。月1回の出庫なら約6.6か月分の更新に相当する。これは係数からの計算で、最適な応答速度の実証ではない。低頻度の出庫では初期値の影響が長く残るため、「異なる2日の出庫があれば信頼できる」と扱わない。
