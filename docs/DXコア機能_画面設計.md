# DXコア機能 画面設計（指定数量監視・欠品予測）

[DXコア機能_要件定義](DXコア機能_要件定義.md) に対応する画面設計。
[UI案](UI案.md) のデザイントークン・下部タブバー構成をそのまま踏襲し、
**既存画面には行・項目の追加のみ**、新規画面は管理タブ配下に1画面のみ追加する。
全体UI（タブバー・既存フロー）の設計は [UI案](UI案.md) を正とし、本書は差分のみを定義する。

## 変更一覧

| 画面 | 変更 | 対象ロール |
|---|---|---|
| ホーム | お知らせバナーに欠品予測行を追加 | 全ロール（自室分のみ） |
| グラフタブ | 予測線（点線）と予測日表示を追加 | 全ロール（自室分のみ） |
| 管理者画面 | 「指定数量モニター」項目を追加（新規画面） | 溶媒庫管理・全体管理者 |
| 通知一覧 | 指定数量超過のアプリ内通知を表示（設計済みの一覧に種別が増えるのみ） | 溶媒庫管理・全体管理者 |

**研究室ロールの画面には指定数量関連の表示を一切追加しない**（要件 F1-8）。

---

## 1. ホーム（既存バナーへの行追加）

[UI案](UI案.md) §2 の「残量低下のお知らせ」バナーに、**下限割れ予測の行**を追加する。
「すでに下限割れ」（⚠・既存）と「もうすぐ下限割れ（予測）」（🕒・新規）を同じカードに同居させ、
新しいカードは増やさない（スクロール最小化）。

```
┌─────────────────────────┐
│ ホーム          [ログアウト]│
│                         │
│ ⚠ 在庫のお知らせ          │
│ ┌─────────────────────┐ │
│ │ ⚠ アセトン 残量 2.0 L │ │ ← 既存：下限割れ（警告色）
│ │ 🕒 メタノール         │ │ ← ★新規：予測行（グレー系）
│ │    7/15頃 下限割れ予測 │ │    タップで詳細情報へ
│ └─────────────────────┘ │
│ （以下、既存カード2枚は変更なし）│
├──🏠──┬─✏️─┬─🔍─┬─📈─┬─⚙️─┤
└─────────────────────────┘
```

- 表示順：下限割れ（⚠）→ 予測日が近い順（🕒）。予測行は最大3件＋「他n件」の折りたたみ。
- 予測が1件もない場合は予測行を出さない（バナー自体の表示条件は既存のまま）。
- 文言は「7/15**頃**」とし、断定表現（「7/15に欠品します」）を避ける。あくまで見通し（F2-5）。

## 2. グラフタブ（予測線の追加）

[UI案](UI案.md) §7 の残量推移グラフに、**実績線の先に点線の予測線**を伸ばし、
下限線との交点＝予測日を明示する。プルダウン等の操作系は変更しない。

```
┌─────────────────────────┐
│ 残量推移グラフ         🏠 │
│ [メタノール ▼] [1ヶ月 ▼] │
│ ┌─────────────────────┐ │
│ │  L        今日        │ │
│ │ 50┤＼      ┆          │ │
│ │ 30┤  ＼＿＿┆          │ │ ← 実線：実績（既存）
│ │ 10┤      ＼┆╲ ╲ ╲    │ │ ← ★点線：予測（新規）
│ │ --┤--------┆------✕--│ │ ← 下限線との交点に✕
│ │   └┬───┬───┬───┬     │ │
│ │   6/10  6/25  7/10    │ │
│ └─────────────────────┘ │
│ 現在残量 32.5 L / 下限 5 L│
│ 🕒 7/15頃 下限割れ予測 ★新規│ ← 予測不能時は非表示
├─🏠─┬─✏️─┬─🔍─┬──📈──┬─⚙️─┤
└─────────────────────────┘
```

- 予測不能（F2-4：出庫実績なし・下限未設定・既に下限割れ）の場合、点線と予測日行を出さないだけで他は既存のまま。

## 3. 管理者画面（項目追加）

[UI案](UI案.md) §10 の管理者画面リストに「📏 指定数量モニター」を1行追加する。

```
│ ┌─────────────────────┐ │
│ │ 🔔 通知一覧         ＞ │ │ ← 既存設計のまま
│ │ 📏 指定数量モニター ＞ │ │ ← ★新規
│ │ 📊 利用履歴分析     ＞ │ │
│ │ ⚙️ 各種設定         ＞ │ │
│ └─────────────────────┘ │
```

## 4. 指定数量モニター ★新規画面（管理タブ配下・管理者のみ）

溶媒庫ごとの現在倍数と溶媒別内訳を1画面で確認する。ファーストビューに要点（倍数と状態）を置く。

```
┌─────────────────────────┐
│ 指定数量モニター       🏠 │
│ ← 管理者画面に戻る        │
│ [溶媒庫 ▼]               │ ← 溶媒庫が複数ある場合の切替
│ ┌─────────────────────┐ │
│ │ 合算倍数  0.84 / 1.0  │ │ ← 状態で色分け：
│ │ ████████░░ ⚠接近     │ │    緑(<0.8)/警告色(0.8-1.0)/赤(≧1.0)
│ │ 警告しきい値 0.8       │ │ ← 「独自しきい値」であることを明記
│ ├─────────────────────┤ │
│ │ 溶媒別内訳（倍数降順）  │ │
│ │ アセトン   120L → 0.30 │ │ ← 白テーブル（既存表と同形式）
│ │ メタノール 100L → 0.25 │ │
│ │ トルエン    58L → 0.29 │ │
│ └─────────────────────┘ │
│ 未対応の通知 2件 →通知一覧 │ ← 通知一覧への導線
├─🏠─┬─✏️─┬─🔍─┬─📈─┬──⚙️──┤
└─────────────────────────┘
```

- `designated_quantity` 未設定の溶媒は内訳の最下部に「対象外（指定数量未設定）」として折りたたみ表示し、設定漏れに気づけるようにする。
- しきい値（0.8）の変更は「各種設定」画面で行う（この画面では表示のみ）。変更時は理由入力＋確認ダイアログ＋監査記録（既存の危険操作の作法に従う）。

## 5. 通知一覧（表示内容の追加のみ）

既存設計（未確認/確認済/対応済のステータス運用）に、種別「指定数量超過」の通知が流れてくるだけで、画面構成の変更はない。0.8以上1.0未満の「接近」は指定数量モニターの状態表示だけとし、通知一覧には追加しない。通知行タップで指定数量モニターへ遷移する導線のみ追加する。

## 6. 画面遷移（差分）

```
管理タブ → 管理者画面 → 指定数量モニター ★新規
                     → 通知一覧 →（行タップ）→ 指定数量モニター ★新規導線
ホーム（予測行タップ）→ 詳細情報（既存画面・変更なし）
```

[画面遷移図](画面遷移図.md) への反映は実装時に行う。
