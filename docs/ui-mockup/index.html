ChemStock 新UI案モックアップ

既存UI（ミントグリーン基調・濃緑ボタン・白カード）に下部タブバー（5タブ）を追加する案。 既存画面の主要な遷移を維持し、研究室の選択・表示はアカウントの所属に合わせる。★新規 が追加要素。
機能フローごとに画面を横並びにし、フレーム間の矢印＋ラベルで遷移（操作・タップ）を示す。 緑のラベル付き ▶ が遷移の操作。破線の枠は分岐の起点（同じ画面から複数へ分岐）を表す。
遷移の全体像は 画面遷移図.md、各画面の仕様は UI案.md を参照。 下部タブバーはログイン以外の全画面に常時表示（各フレームに再掲）。
